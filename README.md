# Glasgow 2026 Transport Forecast

Mini data-science project to forecast 2026 road traffic on a key corridor near a Glasgow 2026 Commonwealth Games venue using DfT road traffic API data.

## MVP goals

- One venue, one nearby DfT traffic count point
- Fetch AADF time series (2000–2024) from DfT API
- Fit simple time-series / regression model to forecast 2026
- Build one Games-day spectator scenario
- Compute a simple "stress index" vs historic peak
- Present findings in a single Jupyter notebook report
